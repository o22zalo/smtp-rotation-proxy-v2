# User Changelog

## Version 2.0
**New Features & Improvements:**
- **Web Dashboard**: A brand new web interface to easily manage your SMTP accounts, routing rules, and view statistics.
- **Multiple Providers**: Quickly add accounts from Gmail, Outlook, Yahoo, Zoho, SendGrid, Mailgun, or custom SMTP servers.
- **Import / Export**: You can now import bulk accounts via CSV/JSON and export your configuration for backup.
- **Override Account**: If your application sends credentials that match an existing account, the proxy will use that specific account instead of rotating.
- **Custom "From" Names**: You can now configure specific "From Name" and "From Address" for each account to ensure your emails look professional.
- **Live Stats & Resets**: View exactly how many emails were sent today/this hour, and reset stats whenever needed.
